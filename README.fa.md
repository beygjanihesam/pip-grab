# pip_grab

**دانلود و نصب کتابخونه‌های پایتون از سریع‌ترین میرر سالم PyPI**

[English](README.md)

pip_grab یه برنامهٔ دسکتاپ کوچیکه (Tkinter، بدون نیاز به کتابخونهٔ اضافه) برای کسایی که
اتصالشون به PyPI کند، ناپایدار یا مسدوده. کتابخونه‌ها رو انتخاب می‌کنی، برنامه یه لیست
بزرگ از میررها رو تست می‌کنه، از سریع‌ترین میرر سالم دانلود می‌کنه و نتیجه رو روی
نسخه‌ای از پایتون که تو انتخاب کردی نصب می‌کنه.

## چرا این پروژه رو ساختم

اگه از ایران پایتون کار کرده باشی، این صحنه رو می‌شناسی: `pip install` می‌زنی، چند دقیقه
هیچی نمی‌شه، بعد خطای timeout می‌گیری. میرر بعدی رو امتحان می‌کنی، اون هم کار نمی‌کنه.
یه ساعت بعد هنوز داری آدرس‌ها رو دستی تست می‌کنی.

از این وضعیت خسته شده بودم، برای همین pip_grab رو ساختم. این برنامه خودش میررها رو
تست می‌کنه، سریع‌ترین میرر سالم رو انتخاب می‌کنه و اگه یکی قطع بود می‌ره سراغ بعدی،
و تو فقط اسم کتابخونه رو می‌دی. می‌تونی فایل‌ها رو هم دانلود کنی و ببری روی یه
کامپیوتر آفلاین.

این اولین پروژهٔ اوپن‌سورس منه. اگه میرر سالم جدیدی می‌شناسی یا باگی دیدی، خوشحال
می‌شم یه issue یا pull request بفرستی.

## پیش‌نیازها

- پایتون ۳.۸ یا بالاتر **همراه با Tkinter** (نصب‌کنندهٔ python.org خودش داره)
- اینترنت (برای دانلود)
- روی ویندوز ساخته و تست شده. روی مک و لینوکس هم باید اجرا بشه ولی خیلی کمتر تست شده.

pip_grab خودش pip همراه نداره. از پایتون‌هایی که روی کامپیوترت نصبن استفاده می‌کنه، و
برای همینه که می‌تونی انتخاب کنی روی کدوم نصب بشه.

## شروع سریع

```
python pip_grab_ui.pyw
```

روی ویندوز می‌تونی روی فایل `pip_grab_ui.pyw` دوبل‌کلیک هم بکنی (پنجرهٔ کنسول باز نمی‌شه).

۱. کتابخونه‌ها رو از لیست انتخاب کن یا تایپ کن.
۲. ببین کدوم پایتون انتخاب شده.
۳. دکمهٔ **Start** رو بزن.

بقیهٔ این صفحه هر بخش پنجره رو توضیح می‌ده.

## طرز استفاده

پنجره چهار بخش داره، بعدش دکمهٔ Start، نوار پیشرفت، جدول نتایج و لاگ.

### ۱) Libraries (کتابخونه‌ها)

- **کادر جستجو و لیست دسته‌ها:** لیست حدود ۱۸۰ کتابخونهٔ پرکاربرد رو فیلتر می‌کنه
  (علم داده، هوش مصنوعی، وب، ابزار توسعه، رابط گرافیکی، بات، صدا و تصویر، امنیت، فایل،
  فارسی).
- **انتخاب:** روی یکی کلیک کن، یا با Ctrl / Shift چندتا انتخاب کن و **Add selected**
  رو بزن. دوبل‌کلیک هم اضافه‌ش می‌کنه.
- **لیست دانلود (سمت راست):** چیزی که واقعاً دانلود می‌شه. می‌تونی مستقیم توش تایپ کنی،
  هر اسم تو یه خط یا با فاصله/کاما جدا. نسخه هم می‌شه داد: `numpy==1.26.4`. هر چی بعد
  از `#` باشه نادیده گرفته می‌شه.
- **Load requirements.txt:** لیست رو از یه فایل requirements پر می‌کنه.
- **Clear:** لیست رو پاک می‌کنه.

می‌تونی هر دو روش رو قاطی کنی: چندتا از لیست اضافه کن و بقیه رو تایپ کن.

### ۲) Python to use (پایتون مورد استفاده)

برنامه کامپیوترت رو اسکن می‌کنه و همهٔ پایتون‌هایی که پیدا کنه رو لیست می‌کنه (از
لانچر `py`، پوشه‌های PATH، و مسیرهای نصب معمول مثل python.org، Microsoft Store، uv،
Anaconda و pyenv).

| ستون | معنی |
|---|---|
| Version | نسخهٔ پایتون |
| pip | `yes` یعنی pip داره، `NO` یعنی نداره (قابل استفاده نیست) |
| Notes | `'python' in cmd` یعنی چیزی که با تایپ `python` تو ترمینال اجرا می‌شه؛ `'py' default` یعنی چیزی که لانچر `py` اجرا می‌کنه |
| Path | مسیر کامل `python.exe` |

روی ردیف مورد نظر کلیک کن. **همهٔ کارها (دانلود، نصب، بررسی) با پایتون انتخاب‌شده انجام
می‌شه**، پس فایل‌های دانلودشده همیشه با اون سازگارن. بعد از نصب یه پایتون جدید، **Rescan**
رو بزن.

**چرا مهمه:** خیلی‌ها چند تا پایتون دارن. کتابخونه‌ای که روی یکی نصب بشه برای بقیه دیده
نمی‌شه و با اینکه نصب «موفق» بوده، `ModuleNotFoundError` می‌گیری. به‌صورت پیش‌فرض همون
پایتونی انتخاب می‌شه که با تایپ `python` تو ترمینال اجرا می‌شه.

### ۳) Destination & options (مقصد و تنظیمات)

- **Folder:** پوشه‌ای که فایل‌های دانلودشده (`.whl` / `.tar.gz`) توش ذخیره می‌شن. پیش‌فرض
  `pip_downloads` تو پوشهٔ کاربره. **Browse...** پوشهٔ دیگه‌ای رو انتخاب می‌کنه و
  **Open folder** بازش می‌کنه.
- **Install after download** (پیش‌فرض روشنه): فایل‌های دانلودشده رو روی پایتون انتخاب‌شده
  نصب می‌کنه و بعد هر کتابخونه رو با `pip show` چک می‌کنه و تو جدول نتایج می‌نویسه
  «Installed <نسخه>». اگه فقط فایل‌ها رو می‌خوای، خاموشش کن.
- **No dependencies:** فقط همون چیزی که نوشتی دانلود می‌شه، نه وابستگی‌هاش. مگه اینکه
  بدونی چی می‌خوای، خاموش بذارش.
- **For another system (skips install):** با پر کردن **platform** و/یا **python** فایل‌ها
  رو برای یه کامپیوتر *دیگه* دانلود می‌کنی، مثلاً ویندوز با پایتون ۳.۱۱:
  - platform: `win_amd64`، `manylinux2014_x86_64`، `macosx_11_0_arm64`، `macosx_10_9_x86_64`
  - python: از `3.8` تا `3.14`

  تو این حالت فقط فایل‌های wheel دانلود می‌شه و چیزی روی کامپیوتر خودت نصب نمی‌شه.

### ۴) Mirrors (میررها)

میرر یه سرور جایگزینه که همون کتابخونه‌های PyPI رو داره. برنامه ۵۵ میرر داخلش داره:
میررهای ایرانی، آدرس‌های رسمی PyPI و تعداد زیادی میرر دانشگاه‌ها و شرکت‌های چینی.

- **Test mirrors:** همه رو هم‌زمان تست می‌کنه. سالم‌ها سبز (`OK`) با زمان پاسخ و
  خراب‌ها قرمز (`Down`) می‌شن.
- **Auto (fastest first)** (پیش‌فرض): موقع Start میررها تست می‌شن و از سریع به کند امتحان
  می‌شن. اگه یکی برای یه کتابخونه شکست بخوره، بعدی استفاده می‌شه.
- **Only selected mirror:** یه ردیف رو انتخاب کن و فقط از همون استفاده کن.
- **Add / Add many:** میرر خودت رو اضافه کن. تو *Add many* هر خط یه میرره، به شکل
  `name|url` یا فقط آدرس. آدرس باید ایندکس «simple» باشه، مثلاً
  `https://example.com/pypi/simple/`.
- **Delete:** میرر انتخاب‌شده رو از لیست حذف می‌کنه.
- **Set as pip default:** برای پایتون انتخاب‌شده دستور
  `pip config set global.index-url <mirror>` رو اجرا می‌کنه، یعنی از این به بعد
  `pip install` معمولی تو ترمینال هم از اون میرر استفاده می‌کنه.

میررهایی که خودت اضافه کنی تو فایل `~/.pip_grab_mirrors.json` ذخیره می‌شن و دفعهٔ بعد
برمی‌گردن.

### Start، Stop و نتایج

- **Start** کار رو شروع می‌کنه و **Stop** لغوش می‌کنه.
- **جدول نتایج** وضعیت هر کتابخونه رو نشون می‌ده: `Queued`، `Downloading...`،
  `Downloaded`، `Installed <نسخه>`، `Failed` یا `Install failed`.
- **لاگ** نشون می‌ده برای هر کتابخونه کدوم میرر امتحان شد و چرا یه تلاش شکست خورد. بعد از
  یه اجرای موفق، دستور نصب همون فایل‌ها روی یه کامپیوتر دیگه رو هم چاپ می‌کنه:
  ```
  pip install --no-index --find-links="C:\path\to\pip_downloads" numpy
  ```

## سناریوهای رایج

**نصب چندتا کتابخونه روی همین کامپیوتر**
تو بخش ۱ انتخابشون کن، بخش ۲ رو چک کن و Start رو بزن.

**آماده کردن کتابخونه‌ها برای کامپیوتر آفلاین**
۱. روی یه کامپیوتر با اینترنت، کتابخونه‌ها رو اضافه کن، **Install after download** رو
   خاموش کن (یا platform/python اون کامپیوتر رو پر کن) و Start رو بزن.
۲. کل پوشهٔ دانلود رو با فلش به کامپیوتر آفلاین ببر.
۳. اون‌جا بزن: `pip install --no-index --find-links="<folder>" numpy`

**اینکه `pip install` معمولی از یه میرر سالم استفاده کنه**
**Test mirrors** رو بزن، یه میرر سبز رو انتخاب کن و **Set as pip default** رو بزن.

## رفع اشکال

**نوشته «Successfully installed» ولی `import x` خطا می‌ده.**
رو یه پایتون دیگه نصب کردی. جدول *Python to use* و ستون *Notes* رو ببین؛ ردیفی که
`'python' in cmd` داره رو انتخاب کن، یا اسکریپتت رو با همون پایتونی اجرا کن که روش
نصب کردی.

**همهٔ میررها `Down` هستن.**
اینترنتت رو چک کن. بعضی شبکه‌ها بعضی میررها رو می‌بندن؛ بعداً دوباره امتحان کن یا میررهایی
که برای تو کار می‌کنن رو اضافه کن. آدرس میررها زیاد عوض می‌شه و برای بعضی میررهای
ایرانی چند مسیر محتمل گذاشتم چون مسیر دقیقشون همیشه مشخص نیست، پس بعضی خطاها طبیعیه.

**«No Python installation was found.»**
پایتون رو از python.org نصب کن (تیک "Add python.exe to PATH" رو بزن) و **Rescan** رو بزن.

**«The selected Python has no pip.»**
ردیف دیگه‌ای رو انتخاب کن، یا برای اون پایتون بزن: `python -m ensurepip`.

**یه کتابخونه روی همهٔ میررها شکست می‌خوره.**
املای اسم و نسخه رو چک کن (لاگ خطای pip رو نشون می‌ده). بعضی کتابخونه‌های کامپایلی برای
نسخه‌های خیلی جدید پایتون فایل آماده ندارن؛ تو بخش ۲ یه پایتون قدیمی‌تر انتخاب کن.

**«pip_grab is already running.»**
هر بار فقط یه نسخه می‌تونه اجرا بشه. پنجرهٔ دیگه رو ببند.

## نکات ایمنی

- میررها سرورهای شخص ثالث هستن. فقط از میررهایی که بهشون اعتماد داری استفاده کن، چون
  کتابخونه‌ای که از یه میرر نامعتبر بیاد می‌تونه کد مخرب داشته باشه.
- برنامه هیچ ردیابی (telemetry) نداره و فقط به سرورهای میررهایی وصل می‌شه که تست یا
  استفاده می‌کنی.
